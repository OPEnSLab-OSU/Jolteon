# Jolteon TEROS 11 bench test, November 13, 2026

The Loomified Feather M0 SDI‑12 build from
`firmware/teros11-sdi/firmware.sketch.bin` was programmed on Jolteon.
The uploader verified 221,804 bytes at offset `0x2000`.
The application returned on COM24 and reported compile time
`Nov 13 2026 11:37:05`.

The attached TEROS 11 returned no detectable start bit at the Feather on
discovery, address 0 acknowledge, address 0 identification, or address 0
measurement. The result repeated after a console-controlled sensor power cycle.

```text
SDI ?! attempts=9 | No response start bit.
SDI 0! attempts=9 | No response start bit.
SDI 0I! attempts=9 | No response start bit.
SDI 0M! attempts=9 | No response start bit.
D5=0 D6=1 A3=1
```

The A3 result confirms the boost enable GPIO state. Sensor supply voltage and
data waveforms are pending physical measurement. Check J_SDI12 pins 1–3 under
load, then compare the field-side data on pin 2 and the Feather-side data on D9
during discovery.
